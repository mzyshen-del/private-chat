# Invite Link Chat Demo

一个基于 Express 和 Socket.IO 的实时聊天室演示。创建房间后生成含访问凭证的邀请链接；持有链接的人可进入房间并读取最近 300 条历史消息。

> 这是作品集演示，不提供端到端加密、实名身份验证或企业级数据保护。请勿用它传输敏感信息。

## 功能与设计

- 服务端使用加密随机数生成房间号和 256 位访问凭证；数据文件只保存凭证的 SHA-256 摘要。
- 房间切换时退出原房间；断线重连后，浏览器重新加入当前房间。
- 消息长度限制为 2000 字，每个连接 10 秒最多发送 5 条；每个连接每分钟最多创建 3 个房间。
- 每个房间最多保存 1000 条消息，加入时返回最近 300 条。
- 聊天内容在浏览器中转义后显示，避免将消息当作 HTML 执行。

## 本地运行

需要 Node.js 20 或更新版本。

```powershell
npm ci
npm start
```

打开 `http://localhost:3000`，填写昵称并点击“创建房间”“进入聊天”。复制邀请链接，在另一个浏览器窗口打开并填写昵称，即可验证双人实时聊天。链接中的凭证位于 URL 片段（`#` 后），不会随页面请求发送到服务器；浏览器会通过 Socket.IO 将凭证提交给应用服务端验证。

```powershell
npm test
```

测试使用临时数据文件，覆盖无效凭证、历史记录、房间隔离、重连、消息长度和频率限制。

## 数据与安全边界

聊天记录以明文保存在服务端 `chat-data.json`，该文件被 Git 忽略。任何持有完整邀请链接的人都拥有该房间的读取和发送权限；昵称可自行填写，不能证明真实身份。请勿公开邀请链接或把真实聊天记录提交到仓库。

本地 JSON 文件适合单实例演示。容器使用临时磁盘时，重建后聊天记录可能丢失；多个实例也不能共用这个文件。若要提供长期在线服务，应改用持久化数据库、共享限流及专门的运维监控。
